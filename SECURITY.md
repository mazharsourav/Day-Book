# Security

## What Day Book does with your data

Day Book keeps everything on your phone. It has no server, no account and no analytics, and it sends nothing anywhere. Backup files are plain text that you save and move yourself.

## Reporting a problem

If you find a security problem, please report it privately and not in a public issue.

1. Open the **Security** tab of this repository.
2. Choose **Report a vulnerability**.
3. Say what you found, which version, and the steps to see it.

I'll read it and reply as soon as I can. This is a one-person project, so please be patient. Please don't share the details publicly until it's fixed.

## Which versions are fixed

Only the latest release gets fixes.

## What counts

- Ways to read, change or lose a person's saved data.
- Ways another app or a web link can make Day Book do something the person didn't ask for.
- Secrets or private files that were published by mistake.

Warnings from `npm audit` in build tools are welcome too, but they are usually not reachable from the app.
